# My Absensi

Aplikasi absensi karyawan (Miauw Project).

Tiga aplikasi Android (Capacitor + Firebase):

- **Karyawan** — absen masuk/keluar (GPS), jadwal shift, slip gaji
- **Owner** — dashboard, karyawan, shift, laporan, slip gaji
- **Dev** — kelola perusahaan & lisensi

Hosting (update banner + file APK): `hosting/` — di-deploy ke https://absensi-miauw-project.web.app/ via GitHub Actions.
